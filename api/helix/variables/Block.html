tag ​

tag: (id) => BlockValue = blockTag

Build a block tag (#namespace:path) - matches any block the tag contains, for if block / fill replace predicate positions. Prefer the typed vanilla ids: Block.tag(BLOCK_TAGS.AIR) -> #minecraft:air (autocompleted, typo-checked). A raw string also works (Block.tag("air")); a leading # is optional (added if absent) and the namespace defaults to minecraft:.
